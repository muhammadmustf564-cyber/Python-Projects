# 🌡️ Temperature Converter

A simple Python program that converts temperatures between Celsius and Fahrenheit.

## 📌 About

The program provides two conversion options:

* Celsius → Fahrenheit
* Fahrenheit → Celsius

The user selects a conversion type, enters the temperature, and the program displays the converted value.

## 🛠️ Concepts Used

* User input
* `float()`
* `if / elif / else`
* Variables
* Arithmetic operations
* Mathematical formulas

## ▶️ How to Run

```bash
python temperature_converter.py
```

## 💻 Conversion Formulas

```text
Fahrenheit = (Celsius × 9/5) + 32

Celsius = (Fahrenheit - 32) × 5/9
```
