# 🧮 Menu-Driven Calculator

A simple command-line calculator built with Python that allows users to perform basic arithmetic operations through a menu.

## 📌 About

This project is a beginner-friendly Python calculator. The user can select an operation from a menu and enter two numbers. The program then performs the selected calculation and displays the result.

## ⚙️ Operations

The calculator supports four basic operations:

* ➕ Addition
* ➖ Subtraction
* ✖️ Multiplication
* ➗ Division

## 🛠️ Concepts Used

* Python Functions
* `while` loop
* `if / elif / else`
* User Input
* `float()` for numerical input
* `try / except` for input validation
* Basic arithmetic operators
* Menu-driven programming

## ▶️ How to Run

Run the following command:

```bash
python calculator.py
```

Then select an operation:

```text
1. Add
2. Subtract
3. Multiply
4. Divide
```

Enter the two numbers when prompted.

## 💻 Example

```text
Select operation.
1.Add
2.Subtract
3.Multiply
4.Divide

Enter Choice (1/2/3/4): 1
Enter first number: 10
Enter second number: 5

10.0 + 5.0 = 15.0
```

## 🎯 Purpose

This project was created to practice Python fundamentals, especially functions, loops, conditional statements, user input, and error handling.
