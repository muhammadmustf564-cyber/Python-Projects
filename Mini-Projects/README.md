## ```. 🎯 Number Guessing Game```

A simple Python game where the computer randomly selects a number between **1 and 100**, and the player tries to guess it.

The program provides **Too High**, **Too Low**, or **Correct** hints and counts the number of attempts.

### Concepts Used

* `random` module
* `while` loop
* Conditional statements
* User input
* Basic game logic
* f-strings

This project was created to practice Python fundamentals and logical problem-solving.
