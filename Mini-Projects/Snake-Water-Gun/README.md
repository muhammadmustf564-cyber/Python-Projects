# 🐍 Snake-Water-Gun

A simple command-line Snake-Water-Gun game built with Python. The player competes against the computer, which randomly selects Snake, Water, or Gun.

## 🎮 Game Rules

* Snake 🐍 beats Water 💧
* Water 💧 beats Gun 🔫
* Gun 🔫 beats Snake 🐍
* Same choice = Draw

## 🛠️ Concepts Used

* `random` module
* Dictionaries
* User input
* `if / elif / else`
* Input validation
* f-strings
* Game logic

## ▶️ How to Run

```bash
python snake_water_gun.py
```

Enter:

* `s` for Snake
* `w` for Water
* `g` for Gun

## 💻 Example

```text
Enter your choice (s/w/g): g
You chose gun
Computer chose snake
You win!
```
## Purpose
This project demonstrates how Python dictionaries, random choices, and conditional logic can be used to build a simple interactive game.
