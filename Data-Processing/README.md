# Python Student Programs

A collection of simple Python programs focused on processing student data using dictionaries, nested data structures, loops, conditions, and basic calculations.

## 📚 Programs Included

* **Students-Above-2-Fail** — Identifies students who have failed in more than two subjects.
* **Fail-Count-Students** — Calculates the number of failed subjects for each student based on their marks.

These programs help practice Python data structures and basic data-processing logic through student-related examples.


# Fail Count Students

A Python program that calculates the number of failed subjects for each student by checking their subject marks.

## 📌 Project Overview

The program stores student names and subject marks using nested data structures. It checks each subject's marks and counts how many subjects each student has failed.

A mark below **50** is considered a failed subject.

## 📊 Example

The program processes each student's marks and produces a result showing:

```text
Student Name → Number of Failed Subjects
```

For example:

```text
Ali → 2 failed subjects
```

## 🛠️ Concepts Practiced

* Python Dictionaries
* Nested Dictionaries
* Lists
* For Loops
* `.values()`
* Conditional Statements
* Counters
* Basic Data Processing

## 🎯 Learning Goal

To practice working with nested data structures and using loops and conditions to process student marks and count failed subjects.

# Students Above 2 Fail

A simple Python program that identifies students who have failed in more than two subjects.

## 📌 Project Overview

The program stores student names and their number of failed subjects in a dictionary. It checks the fail count of each student and displays students whose failed subjects are greater than 2.

## 📊 Example

If a student has:

* 3 failed subjects → Displayed
* 4 failed subjects → Displayed
* 2 failed subjects → Not displayed

## 🛠️ Concepts Practiced

* Python Dictionaries
* For Loops
* Conditional Statements
* Dictionary Access
* Data Filtering

## 🎯 Learning Goal

To practice using dictionaries, loops, and conditions to filter student data based on a specific requirement.
