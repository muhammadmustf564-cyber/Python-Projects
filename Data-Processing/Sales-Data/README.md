# Sales-Data

A practical **data-cleaning and preprocessing project** focused on preparing and organizing sales data using **Python and Pandas**.

## Project Structure

* `Data/` — Contains the original dirty dataset, cleaned datasets, and input/output screenshots.
* `Scripts/` — Contains the Python script used to clean and process the sales data.

## Tasks Performed

* Removed duplicate records
* Handled missing `Price` and `Quantity` values
* Calculated `Total_Amount`
* Exported cleaned data to CSV and Excel
* Displayed the cleaned dataset

## Purpose

The purpose of this project is to practice **data cleaning and preprocessing using Python**, demonstrating how raw sales data can be cleaned, transformed, and saved into usable formats.

## Tools & Technologies

* Python
* Pandas
* CSV
* Excel
