# Sales Data

A practical data-cleaning project focused on preparing and organizing sales data using Python.

## Project Structure

* `Data/` — Contains the original dirty dataset and the cleaned datasets.
* `Scripts/` — Contains the Python script used to clean and process the sales data.

## Purpose

The purpose of this project is to practice data cleaning and preprocessing using Python. It demonstrates how raw sales data can be cleaned, transformed, and saved into usable formats.

## Tools & Technologies

* Python
* Pandas
* CSV
* Excel
