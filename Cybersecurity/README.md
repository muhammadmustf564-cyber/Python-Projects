A beginner Python project that implements username and password authentication with a 3-attempt limit, account locking, error handling, and login activity logging.

## ``` 🔐 Login-System```

A basic Python authentication system that verifies a predefined username and password.

The user gets **three login attempts**. Correct credentials grant access, while three failed attempts result in the account being locked.

### Concepts Used

* Functions
* Loops
* Conditional statements
* User input
* Authentication logic
* Login attempt control

### Run

```bash
python login_system.py
```

This project was created to practice Python fundamentals and basic cybersecurity authentication concepts.
