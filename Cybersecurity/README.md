## ```🔐 Secure-Login-System```

A Python-based authentication system that supports multiple users, limits login attempts, and logs successful and failed login attempts.

### Features

* Multiple users
* 3 login attempts
* Account lockout
* Login activity logging

### Concepts Used

* Dictionaries
* Loops
* Conditional statements
* File handling
* `try / except`
* Authentication & logging

### Run

```bash
python secure_login_system.py
```

This project demonstrates basic authentication, access control, and security logging using Python.


  
## ```🔐 Login-System```

A basic Python authentication system that verifies a predefined username and password.

The user gets **three login attempts**. Correct credentials grant access, while three failed attempts result in the account being locked.

### Concepts Used

* Functions
* Loops
* Conditional statements
* User input
* Authentication logic
* Login attempt control

### Run

```bash
python login_system.py
```
This project demonstrates basic username/password authentication with limited login attempts.


## ```🔑 Password Checker```

A Python program that checks password strength based on:

* Minimum 9 characters
* Uppercase and lowercase letters
* Numbers
* Special characters

### Concepts Used

`any()`, string methods, user input, and conditional statements.

## 🎯 Purpose

This project demonstrates how Python can be used to validate basic password-strength requirements.
