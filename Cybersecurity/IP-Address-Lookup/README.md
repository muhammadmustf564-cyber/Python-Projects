# 🌐 IP Address Lookup

A simple Python program that finds the IP address associated with a website or domain name.

## 📌 About

The program takes a website or domain name from the user and uses Python's `socket` module to resolve it to an IP address.

It also handles invalid or unavailable domain names using exception handling.

## 🛠️ Concepts Used

* `socket` module
* `socket.gethostbyname()`
* User input
* `try / except`
* DNS hostname resolution
* Error handling

## ▶️ How to Run

```bash
python ip_address_lookup.py
```

Enter a website or domain name when prompted.

## 💻 Example

```text
Enter website: google.com
IP Address: 142.250.xxx.xxx
```

## 🔐 Security Relevance

IP address and DNS lookup are fundamental networking concepts that are useful for understanding network reconnaissance and cybersecurity.

## 🎯 Purpose

This project demonstrates how Python can be used to perform basic DNS and IP address lookups, supporting fundamental networking and cybersecurity concepts.
