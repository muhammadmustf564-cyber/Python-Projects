# log-file-scanner
Python script to scan log files and detect lines containing errors, warnings, or failed messages.

# Log File Scanner (Python)
A simple Python script that reads a log file line by line and prints all lines containing specific keywords such as "error", "failed", and "warning".

## Features
- Case-insensitive search
- Displays line numbers
- Easy to extend keyword list

## Example Output
Line 2: error: file not found
Line 4: ERROR: connection failed
Line 5: warning: your system in danger

## Technologies Used
- Python (File Handling, Loops, Conditions)
